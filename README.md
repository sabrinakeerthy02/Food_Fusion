🍽️ Food_Fusion – Food & Restaurant Website

📌 Project Overview

FoodFusion is a simple and attractive food and restaurant website developed using HTML5 and CSS3. The website provides users with an elegant interface to explore food items, view images, learn about the restaurant, and book a table.

The main purpose of this project is to practice HTML structure, CSS styling, navigation, images, links, and webpage design.

🛠️ Technologies Used

* HTML5 – To create the structure of the website.
* CSS3 – To design and style the webpage.

✨ Website Features

* Attractive navigation bar.
* Restaurant logo and food-related images.
* Beautiful homepage design.
* Food and restaurant information.
* Book a Table section.
* External image resources.
* Attractive colors, fonts, and layouts.
* User-friendly interface.

🧱 HTML Elements and Attributes Used

1. Basic HTML Structure

* <!DOCTYPE html> – Defines the document type.
* <html> – Root element of the webpage.
* <head> – Contains page information.
* <title> – Sets the webpage title.
* <body> – Contains visible webpage content.
* <meta> – Provides metadata.
* <link> – Connects the external CSS file.

2. Navigation Bar

* <nav> – Creates the navigation section.
* <a> – Creates navigation links.
* href – Specifies the destination of a link.

3. Images and Logo

* <img> – Displays images on the webpage.
* src – Specifies the image source.
* alt – Provides alternative text for an image.
* width – Sets image width.
* height – Sets image height.

4. Book a Table Section

* <section> – Creates a separate content section.
* <div> – Groups related elements.
* <h1>, <h2>, <h3> – Defines headings.
* <p> – Displays paragraphs.
* <button> – Creates a clickable button.

5. External Resources

External image resources are used to make the website visually attractive. These may include food images, restaurant-related pictures, and cutlery images.

🎨 CSS Properties Used

1. Layout and Spacing

* margin – Creates space outside an element.
* padding – Creates space inside an element.
* width – Sets element width.
* height – Sets element height.
* display – Controls how an element is displayed.
* position – Controls element positioning.

2. Colors and Background

* color – Changes text color.
* background-color – Sets background color.
* background-image – Adds a background image.

3. Text Styling

* font-family – Changes the font style.
* font-size – Sets text size.
* font-weight – Controls text thickness.
* text-align – Aligns text.
* text-decoration – Adds or removes text decoration.

4. Image Styling

* border-radius – Makes image corners rounded.
* object-fit – Controls how an image fits inside its container.

5. Navigation and Button Styling

* display – Arranges navigation elements.
* gap – Adds space between elements.
* padding – Adjusts internal spacing.
* cursor – Changes the mouse pointer.
* transition – Creates smooth visual effects.
