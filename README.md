# Food_Fusion

A responsive food website project built using HTML and CSS.
Food_Fusion is a food website project developed using HTML and CSS. It includes a homepage with images and a designed layout.

Technologies Used:

* HTML
* CSS

Project Files:

* index.html – Main HTML file
* CSS file – Styles the website
* Two image files – Used in the website

Project Purpose:

This project was created to practice HTML and CSS and improve basic web development skills.
